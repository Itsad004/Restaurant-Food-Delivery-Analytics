# 🍽️ Restaurant & Food Delivery Analytics Dashboard

An end-to-end Business Intelligence project built using **Microsoft Power BI, DAX, and Excel** to analyse restaurant performance, customer behaviour, revenue trends, and food delivery operations.

## 📌 Project Overview

This project focuses on analysing restaurant and food delivery business data to generate meaningful business insights through interactive dashboards and KPI reporting.

The dashboard helps understand business performance, customer retention, restaurant ratings, order trends, and delivery efficiency.

## 🛠️ Tools & Technologies

- **Power BI:** Interactive dashboards and data visualization
- **DAX:** Calculated columns, measures, and KPI calculations
- **Microsoft Excel:** Dataset management and data preparation

## 📊 Dataset Overview

The project uses four data tables:

| Dataset | Records |
|---|---:|
| Orders | 200,000 |
| Customers | 20,000 |
| Restaurants | 56,250 |
| DateTable | 1,000 |

## 🚀 How to Use

1. Download the Power BI `.pbix` file.
2. Download the Excel dataset.
3. Open the PBIX file using Microsoft Power BI Desktop.
4. If prompted, update the Excel data source path.
5. Refresh the data to explore the interactive dashboard.
6. Refer to the DAX documentation for calculated columns and measures.
